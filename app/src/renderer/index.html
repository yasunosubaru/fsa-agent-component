命令执行记录

每一条命令都经 sbx exec 送进沙盒内核执行。每条记录自带凭证： 内核版本、PID 命名空间、网络命名空间、Windows 盘是否可见、运行用户。 凭证对不上说明这条命令没在沙盒里执行。

还没有命令记录。上面的按钮或任何 agent 在沙盒中执行命令都会出现在这里。

定制（MCP / 技能）

点「生成模板」查看各目标应写入的内容。
